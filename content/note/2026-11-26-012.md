Dark mode actually looks pretty good, even via this shortcut.

```
@media (prefers-color-scheme: dark) {
  html { 
    background-color: #ffffff;
    filter: invert(90%) hue-rotate(180deg); 
  } 
  img, video, iframe { 
    filter: invert(90%) hue-rotate(180deg); 
  } 
}
```
