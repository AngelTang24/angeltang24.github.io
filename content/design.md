`angeltang24.github.io` is built with [Hugo](https://gohugo.io/) and deployed with GitHub Pages. 

## Typography
Only font used is [Fira Sans](https://fonts.google.com/specimen/Fira+Sans). This probably won't change for a long time. 

## Colours
The colour palette was generated [here](https://coolors.co/2e3c4f-a3bbad-c94a3a-f7b32b-f9f9f9). I use Charcoal Blue for body and header text, a lighter tint (80% white) of Ash Grey for content background colour, Bright Snow for the remaining background colour, and Vibrant Coral for links.

## Inspiration
I scrolled [Ask HN: Most beautiful personal blog UI you have ever seen?](https://news.ycombinator.com/item?id=47302553) for very long to get inspiration. Uninspired me did not produce great work. 

Much thanks to the following web pages:
- [gwern.net](https://gwern.net/): My Header 2 formatting is quite similar; I also took inspiration from his [Site](https://gwern.net/about) page. 
- [coryd.dev](https://www.coryd.dev/): Links. 
- [turntrout.com](https://turntrout.com/): His meticulous [design](https://turntrout.com/design) was what inspired me to make a web page of my own, though the attention to detail cannot rival his
- [anhvn.com](https://anhvn.com/): I also consulted [this media logging page](https://www.are.na/anh-vn/channels), which gained me access to a whole load of interesting web pages. 
- [meyerweb.com](https://meyerweb.com/): His sleek design motivated me to consider adding a header image and side nav bar. 
- [xmin.yihui.org](https://xmin.yihui.org/): This theme was consulted. The code block's drop shadow feature was inspired here.
- [ssg.evanchen.cc](https://ssg.evanchen.cc/): The T-shaped layout was inspired here. Also I should learn how to use Git properly.
